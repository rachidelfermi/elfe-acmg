# BS2 source-to-rule matrix

| Source | Scope and verified rule | Implementation |
| --- | --- | --- |
| [Richards et al., ACMG/AMP 2015](https://pmc.ncbi.nlm.nih.gov/articles/pmid/25741868/) | Strong BS2: a well documented healthy adult with homozygous genotype for a recessive disorder, heterozygous genotype for a dominant disorder, or hemizygous genotype for an X-linked disorder, with full penetrance expected at an early age. | General AD, AR, XL paths; one qualifying observation gives Strong. The input must explicitly attest full penetrance, early onset, adult status, age beyond onset, clinical unaffected status, reliable genotype, and a valid compatible gene-disease context. |
| [ClinGen SVI guidance index](https://clinicalgenome.org/working-groups/sequence-variant-interpretation/) | SVI recommendations and approved VCEP specifications are separate authorities. The SVI working group retired in April 2025. | No universal BS2 count or strength upgrade is inferred from SVI material. |
| [ClinGen RUNX1 MM-VCEP GN008 v3.0.0](https://cspec.genome.network/cspec/ui/svi/doc/GN008?version=3.0.0) | BS2 is not applicable to RUNX1 familial platelet disorder with associated myeloid malignancy because penetrance is incomplete and malignancy onset is later. | `gene_id=RUNX1`, `disease_id=FPD_AML` returns `NOT_APPLICABLE`. |
| [ClinGen Rett/Angelman-like VCEP publication](https://pmc.ncbi.nlm.nih.gov/articles/PMC9135956/) | Strong BS2 requires two unaffected adults with heterozygous FOXG1/TCF4, hemizygous SLC9A6, or heterozygous/hemizygous CDKL5/MECP2 genotype; UBE3A requires four unrelated individuals or related individuals with maternal inheritance. Related observations are permitted by the published rule. Population database genotypes alone do not confirm phenotype. | Applies only when `disease_id=RETT_ANGELMAN_LIKE`, `vcep_applicable=true`, and `vcep_specification_version="2022 publication"`. Each person must have an ID, documented phenotype and eligible genotype; UBE3A also requires explicit unrelated status or maternal allele status. |

All tests use synthetic fixtures. No externally curated variant case set is bundled. The symbolic `RETT_ANGELMAN_LIKE` disease scope is an explicit caller assertion of panel applicability, not an ontology identifier; users must establish the actual gene-disease fit before setting `vcep_applicable=true`.

The engine does not infer the onset distribution, penetrance, genotype validity, clinical health, independent identity, or VCEP applicability from a gene symbol or a population database. It does not implement other criteria, classification combinations, or arbitrary user-provided thresholds. Published VCEP rules outside the pinned scopes require a future reviewed code update.
