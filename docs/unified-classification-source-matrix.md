## Clinical validation boundary

The integration tests exercise published decision patterns using synthetic variants. They are not a validation set of expert-curated clinical cases. The evaluator packages contain criterion-specific source matrices, but this repository does not include a complete, reconciled VCEP specification snapshot. Therefore, the unified output is decision support for supplied, traceable evidence and should not be treated as a clinically validated autonomous classifier.
