# Source to rule matrix

| Rule | Authority | Implementation |
| --- | --- | --- |
| PM6 means assumed de novo with maternity and paternity unconfirmed; PS2 requires both confirmed | [Richards et al. 2015](https://pubmed.ncbi.nlm.nih.gov/25741868/) | Confirmed observations are referred to PS2. Both parents must have reliable negative variant tests for either category. |
| Assumed de novo points: highly specific 1; consistent 0.5; consistent with high genetic heterogeneity 0.25; inconsistent 0 | [ClinGen SVI PS2/PM6 v1.1, Table 1](https://clinicalgenome.org/site/assets/files/3461/svi_proposal_for_de_novo_criteria_v1_1.pdf) | Score each independent eligible case. Heterogeneous row contributes at most 1 point in total. |
| Confirmed de novo points: highly specific 2; consistent 1; heterogeneous 0.5 | [ClinGen SVI PS2/PM6 v1.1, Table 1](https://clinicalgenome.org/site/assets/files/3461/svi_proposal_for_de_novo_criteria_v1_1.pdf) | Retain for mixed-series PS2 referral; never award those points as PM6 alone. |
| Supporting >=0.5, Moderate >=1, Strong >=2, Very Strong >=4 | [ClinGen SVI PS2/PM6 v1.1, Table 2](https://clinicalgenome.org/site/assets/files/3461/svi_proposal_for_de_novo_criteria_v1_1.pdf) | Compare capped point total to thresholds. These are de novo evidence points, not ACMG classification points. |
| Mixed confirmed and assumed observations are pooled once and use PS2 | [ClinGen SVI PS2/PM6 v1.1, example before Table 1](https://clinicalgenome.org/site/assets/files/3461/svi_proposal_for_de_novo_criteria_v1_1.pdf) | Return `NOT_APPLICABLE` with PS2 delegation and the pooled score. |
| AR disorder without a second P/LP allele: decrease strength one level; apparent germline mosaicism requires confirmed parental relationships | [ClinGen SVI PS2/PM6 v1.1, additional considerations](https://clinicalgenome.org/site/assets/files/3461/svi_proposal_for_de_novo_criteria_v1_1.pdf) | Apply after scoring; reject an assumed apparent germline mosaic series. |
| Applicable gene/disease VCEP requirements supersede general rules | [ClinGen Variant Curation SOP v2.0](https://clinicalgenome.org/site/assets/files/5933/variant_curation_sop_2_0_jan_2021.pdf) | Select the built-in HNF1A scope automatically; reject an explicit unsupported or out-of-scope profile as `UNDETERMINED`. |
| HNF1A/monogenic diabetes PM6 is subsumed by PS2; SVI points and MDEP phenotype restrictions apply | [ClinGen Monogenic Diabetes VCEP v3.1](https://calculator.clinicalgenome.org/cspec/ui/svi/doc/467903868?version=1.1.0) | Automatically select this scope and delegate once to PS2. Enforce documented autoimmune and affected-parent exclusions and maximum-phenotype PP4 requirements. |
| SLC9A6/Christianson syndrome: a gene-consistent neurodevelopmental phenotype receives 1 assumed or 2 confirmed de novo points; two and four independent assumed cases reach Strong and Very Strong | [ClinGen Rett and Angelman-like VCEP v6.0](https://cspec.clinicalgenome.org/cspec/ui/svi/doc/GN033) | Automatically select this scope and require the curator's phenotype conclusion. |

No universal read-depth, allele-balance or call-quality number is asserted by these sources. The evaluator accepts an already-curated adequacy conclusion and treats an explicitly poor result as exclusion. Synthetic tests exercise rules; they are not externally validated variant classifications.
